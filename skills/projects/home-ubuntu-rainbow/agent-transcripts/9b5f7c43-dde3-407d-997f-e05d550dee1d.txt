## 개요
`adm/online_up.php`에서 관리자가 등록하는 온라인 견적 제품 데이터가 유저 화면에서 어떻게 연동되어 사용되는지 분석한 문서입니다.

---

## 1. 관리자 등록 프로세스

### 1.1 등록 화면
**파일**: `adm/online_up.php`

관리자가 다음 정보를 입력하는 폼을 제공합니다:
- **차종** (sel1): `online_data` 테이블에서 `data_type1='차종'`인 데이터 조회
- **국산/수입** (sel2): `online_data` 테이블에서 `data_type1='국산/수입'`인 데이터 조회
- **시공위치** (sel3): `online_data` 테이블에서 `data_type1='시공위치'`인 데이터 조회
- **시공제품** (sel4): `online_data` 테이블에서 `data_type1='제품'`인 `data_name1` 조회
- **농도** (sel5): `online_data` 테이블에서 `data_type1='농도'`인 데이터 조회
- **가격** (sel6): 직접 입력

### 1.2 데이터 저장
**파일**: `adm/online/online_list_update.php`

폼 제출 시 (`data_val='online_up_chk'`):
1. **유효성 검증**: 모든 필수 필드 확인
2. **중복 체크**: 동일한 조건의 제품이 이미 존재하는지 확인
   ```sql
   SELECT n_id FROM sigong_data 
   WHERE data_type1 = '제품'
     AND data_type2 = '{차종}'
     AND data_name = '{국산/수입}'
     AND data_name2 = '{시공위치}'
     AND data_name3 = '{시공제품}'
     AND data_option1 = '{농도}'
   ```
3. **데이터 저장**: 중복이 없을 경우 `sigong_data` 테이블에 INSERT
   ```sql
   INSERT INTO sigong_data (
       data_type1,      -- '제품'
       data_type2,      -- 차종
       data_name,       -- 국산/수입
       data_name2,      -- 시공위치
       data_name3,      -- 시공제품
       data_option1,    -- 농도
       data_option2,    -- 가격
       data_option3     -- 1 (활성화)
   ) VALUES (...)
   ```

## 2. 유저 화면 연동 프로세스

### 2.1 견적 입력 화면
**파일**: `theme/basic/skin/board/board_02/list.skin.php`

유저가 견적을 입력하는 화면에서 다음 단계로 진행됩니다:

#### 2.1.1 기본 정보 선택
- **시공희망지역**: 시/도, 시/군/구 선택
- **차종**: `online_data` 테이블에서 `data_type1='차종'`인 데이터를 라디오 버튼으로 표시
- **구분**: `online_data` 테이블에서 `data_type1='국산/수입'`인 데이터 (기본값: 국산)

#### 2.1.2 시공정보 선택 (AJAX 연동)
차종과 구분 선택 후, 시공위치별 아이콘 클릭 시 AJAX로 제품 목록을 조회합니다:

**전면 (icon_01)**
- 클릭 시: `/theme/basic/skin/include/online_ajax1.php` 호출
- 조회 조건:
  ```sql
  SELECT DISTINCT data_name3 
  FROM sigong_data 
  WHERE data_type1 = '제품'
    AND data_type2 = '{차종}'
    AND data_name = '{국산/수입}'
    AND data_name2 = '전면'
    AND data_option3 = 1
  ```
- 제품 선택 시: `/theme/basic/skin/include/online_ajax1_1.php` 호출하여 농도 목록 조회
  ```sql
  SELECT DISTINCT data_option1 
  FROM sigong_data 
  WHERE data_type1 = '제품'
    AND data_type2 = '{차종}'
    AND data_name = '{국산/수입}'
    AND data_name2 = '전면'
    AND data_name3 = '{제품명}'
    AND data_option3 = 1
  ```

**측후면 (icon_07)**
- AJAX 파일: `online_ajax2.php`, `online_ajax2_1.php`
- 조회 조건: `data_name2 = '측후면'`

**썬루프 (icon_03)**
- AJAX 파일: `online_ajax3.php`, `online_ajax3_1.php`
- 조회 조건: `data_name2 = '썬루프'`

**파노라마 썬루프 (icon_04)**
- AJAX 파일: `online_ajax4.php`, `online_ajax4_1.php`
- 조회 조건: `data_name2 = '파노라마 썬루프'`

### 2.2 견적 결과 화면
**파일**: `theme/basic/skin/board/board_02/write.skin.php`

## 6. 핵심 포인트

1. **데이터 저장 위치**: 관리자가 등록한 제품 정보는 `sigong_data` 테이블에 저장됩니다.
2. **활성화 여부**: `data_option3 = 1`인 데이터만 유저 화면에 표시됩니다.
3. **중복 방지**: 동일한 조건(차종, 국산/수입, 시공위치, 제품, 농도)의 제품은 중복 등록이 불가능합니다.
4. **동적 필터링**: 유저가 차종과 구분을 선택하면, 해당 조건에 맞는 제품만 AJAX로 조회되어 표시됩니다.
5. **가격 계산**: 선택한 모든 시공위치의 가격을 합산하여 최종 견적 금액을 계산합니다.

## 주요 분석 결과

### 데이터 흐름
1. 관리자 등록 (`adm/online_up.php`)
   - 차종, 국산/수입, 시공위치, 시공제품, 농도, 가격 입력
   - 폼 제출 → `adm/online/online_list_update.php`

2. 데이터 저장 (`adm/online/online_list_update.php`)
   - 중복 체크 후 `sigong_data` 테이블에 저장
   - 저장 구조:
     - `data_type1` = '제품'
     - `data_type2` = 차종
     - `data_name` = 국산/수입
     - `data_name2` = 시공위치
     - `data_name3` = 시공제품
     - `data_option1` = 농도
     - `data_option2` = 가격
     - `data_option3` = 1 (활성화)

3. 유저 화면 연동 (`board_02` 게시판)
   - 견적 입력 화면에서 차종/구분 선택
   - 시공위치 아이콘 클릭 시 AJAX로 제품 목록 조회
   - 제품 선택 시 농도 목록 조회
   - 견적 제출 후 가격 계산 및 표시

### 핵심 연동 파일
- AJAX 엔드포인트: `online_ajax1.php` ~ `online_ajax4_1.php` (시공위치별 제품/농도 조회)
- 견적 입력: `theme/basic/skin/board/board_02/list.skin.php`
- 견적 결과: `theme/basic/skin/board/board_02/write.skin.php`
