- **기부자 정보**: 기부자 유형 → `wr_16`, 회사명/사업자번호 → `wr_17`/`wr_18`, 학교관계 → `wr_29`, 주소/상세/기타 → `wr_36`/`wr_37`/`wr_38`, 약정자 성명 → `wr_24`, 권유자 → `wr_1`/`wr_2`/`wr_39`/`wr_40`
- 납입기간 구데이터 호환: `wr_2` 값이 있으면 `$period_type`으로 사용

### 3. 6가지 캠페인별 추가 블록
- **fund**: 추가 필드 없음
- **matching**: `wr_31`(신청구좌), `wr_32`(출연기간)
- **usuri**: `wr_31`(기부기간), `wr_32`(동의/미동의)
- **shop**: `wr_31`~`wr_35`(업종, 업체명, 대표자, 업체소개, 지정일)
- **small_love**: 안내 문구만
- **tuition_plus**: 안내 문구 + 직접입력 비활성

### 4. JS
- `ca_name` 변경 시 `campaign_type` 갱신, 해당 `.campaign-extra-section`만 표시
- `tuition_plus`일 때 금액 직접입력 비활성화
- 제출 시 숨겨진 캠페인 extra 입력 비활성화(중복 전송 방지), 금액은 `wr_5` hidden으로만 전송

### 5. 검증 (fwrite_submit)
- matching: `wr_31`, `wr_32` 필수
- usuri: `wr_31`, `wr_32`(동의) 필수
- shop: `wr_31`~`wr_33`, `wr_35` 필수
- tuition_plus: 정해진 금액 라디오 선택 필수

### 6. 스타일
- `style.css`: `.campaign-extra-section.hidden`, `.campaign-extra-desc` 추가
